# Code of Conduct

## Our Pledge

We want the OpenBrau community to be welcoming to brewers, developers, designers, documentation writers, and curious tinkerers of all experience levels.

Participants are expected to help create a community that is:

- respectful,
- inclusive,
- collaborative,
- constructive, and
- kind.

## Expected Behavior

Examples of positive behavior include:

- assuming good intent,
- offering actionable feedback,
- being respectful of different skill levels and backgrounds,
- welcoming newcomers,
- keeping technical disagreements focused on the work, and
- accepting correction gracefully.

## Unacceptable Behavior

Examples of unacceptable behavior include:

- harassment or discrimination,
- personal attacks,
- trolling or deliberately disruptive behavior,
- sexualized language or imagery in inappropriate contexts,
- doxxing or sharing private information without permission, and
- sustained hostility that makes collaboration harder.

## Scope

This Code of Conduct applies in project spaces, including issues, pull requests, discussions, and other community interactions conducted under the OpenBrau project umbrella.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, or other contributions that violate this Code of Conduct.

Repeated or severe violations may result in temporary or permanent exclusion from the project community.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the project maintainers through a documented project contact method.

If a dedicated security or contact address is later added, this file should be updated to point to it directly.

## Final Note

Be excellent to each other. Good beer takes healthy fermentation; good open source takes healthy collaboration.
